3.2.1 — Unsigned Integers
▼

An unsigned integer is a whole number that is always positive (or zero). In binary, every bit contributes positively to the value — exactly as you learned in Topic 3.1.

DEFINITION

Unsigned integer: A whole number that has no sign — it can only represent zero or positive values. All bits represent magnitude.

🔢 8-bit Unsigned Range

With 8 bits, all combinations from 00000000 to 11111111 are used to count up from 0:

Minimum: 0 Maximum: 255

The formula for the range of an n-bit unsigned integer is:

0 to 2ⁿ − 1
For 8 bits: 0 to 2⁸ − 1 = 0 to 255
For 4 bits: 0 to 2⁴ − 1 = 0 to 15

📋 Example

Represent 200 as an 8-bit unsigned integer:

128 64 32 16 8 4 2 1
1 1 0 0 1 0 0 0

128 + 64 + 8 = 200 ✓ → Binary: 11001000

💡 When to use unsigned? When you know the value is always ≥ 0 — e.g., pixel colour values, counts of items, ASCII codes. You get double the positive range compared to signed!
3.2.2 — Sign and Magnitude
▼

To represent negative numbers, we need to use one bit as a sign indicator. The sign and magnitude method is the most intuitive approach.

DEFINITION

Sign bit: The Most Significant Bit (MSB — leftmost bit) is used purely as a sign indicator.

0 in the MSB = positive  |  1 in the MSB = negative

The remaining 7 bits represent the magnitude (size) of the number, just like unsigned binary.

🔢 8-bit Sign & Magnitude Range

Minimum: −127 Maximum: +127

Formula for n-bit sign & magnitude:

−(2ⁿ⁻¹ − 1) to +(2ⁿ⁻¹ − 1)
For 8 bits: −127 to +127

✏️ Writing Sign & Magnitude

  1. Convert the magnitude (ignore the sign) to 7-bit binary
  2. If the number is positive → MSB = 0
  3. If the number is negative → MSB = 1
  4. Combine: sign bit + 7 magnitude bits
Example: Write −45 in 8-bit sign & magnitude
1. 45 in binary = 0101101 (7 bits)
2. Negative → MSB = 1
3. Result: 1 0101101 = 10101101
⚠️ Problem with sign & magnitude: There are two representations of zero: 00000000 (+0) and 10000000 (−0). This wastes a pattern and makes arithmetic circuits more complex. This is why two's complement is preferred.
3.2.3 — Two's Complement
▼

Two's complement is the standard method used by real computers to represent signed integers. It's cleverer than sign & magnitude — the MSB still signals negativity, but instead of representing a positive weight, it contributes a negative weight.

DEFINITION

Two's complement: A method of representing signed integers where the MSB has a negative place value (−128 for 8-bit), and all other bits have their normal positive values. Only one representation of zero exists.

🔢 8-bit Two's Complement Range

Minimum: −128 Maximum: +127

Formula for n-bit two's complement:

−2ⁿ⁻¹ to +(2ⁿ⁻¹ − 1)
For 8 bits: −128 to +127

📋 The Bit Weights in Two's Complement (8-bit)

Bit 7 (MSB)Bit 6Bit 5Bit 4Bit 3Bit 2Bit 1Bit 0 (LSB)
−128 +64+32+16+8+4+2+1

📖 Reading Two's Complement

Example 1 (positive): What is 01001101?

MSB = 0 → contributes −128 × 0 = 0
Remaining bits: 64+8+4+1 = 77
Total: 0 + 77 = +77

Example 2 (negative): What is 11110110?

MSB = 1 → contributes −128
Remaining bits: 64+32+16+4+2 = 118
Total: −128 + 118 = −10

✏️ Converting a Negative Denary to Two's Complement

There are two equivalent methods. Learn both — examiners may specify one!

Method 1: Invert & Add 1

  1. Write the positive version in 8-bit unsigned binary
  2. Invert all the bits (flip every 0 to 1 and every 1 to 0) — this is called "one's complement"
  3. Add 1 to the result
Example: Write −45 in 8-bit two's complement
Step 1: +45 = 00101101
Step 2: Invert → 11010010
Step 3: Add 1 → 11010010 + 1 = 11010011

Check: −128 + 64 + 16 + 2 + 1 = −128 + 83 = −45 ✓

Method 2: Negative MSB Weight

  1. Set the MSB to 1 (contributing −128)
  2. Work out what positive value you need to add to −128 to reach your target: target − (−128) = amount needed
  3. Write that amount in the remaining 7 bits using normal binary
Example: Write −45 using the weight method
MSB = 1 → we have −128
Need: −128 + ? = −45 → ? = 83
83 in 7-bit binary = 1010011
Result: 11010011 = 11010011 ✓
💡 Spotting negatives: In two's complement, if the MSB is 1, the number is always negative. If MSB is 0, it's always positive (or zero).

▼

You need to be able to work out the range of values for any number of bits, for each representation method.

📐 Summary of Formulae

📋 Worked Examples with Different Bit Widths

4-bit numbers:
Unsigned: 0 to 2⁴−1 = 0 to 15
Sign & Magnitude: −7 to +7
Two's Complement: −8 to +7
16-bit numbers:
Unsigned: 0 to 2¹⁶−1 = 0 to 65,535
Sign & Magnitude: −32,767 to +32,767
Two's Complement: −32,768 to +32,767
💡 Exam shortcut: The number of distinct values is always 2ⁿ regardless of representation. For 8 bits that's 256 values — signed representations just split them between negative and positive!

⚠️ Overflow

Overflow occurs when the result of an arithmetic operation falls outside the representable range.

Example: 8-bit two's complement. If we try to store +128, it's out of range (max is +127). The bit pattern 10000000 would be interpreted as −128, not +128 — that's an overflow error!

Question 1 (Easy) [2 marks]

State the range of values that can be stored using 8-bit unsigned binary.

Mark Scheme:
• Minimum value: 0 [1 mark]
• Maximum value: 255 [1 mark]
Accept: "0 to 255" for both marks. Accept formula: 0 to 2⁸ − 1.
Question 2 (Medium) [3 marks]

Convert the 8-bit two's complement number 11001010 to denary. Show your working.

Mark Scheme:
• MSB = 1 → contributes −128 [1 mark]
• Remaining bits 1001010: 64 + 8 + 2 = 74 [1 mark]
• −128 + 74 = −54 [1 mark]
Question 3 (Medium) [3 marks]

Show how −37 would be represented as an 8-bit two's complement number. Show each step.

Mark Scheme:
• +37 in binary = 00100101 [1 mark]
• Invert all bits → 11011010 [1 mark]
• Add 1 → 11011011 [1 mark]
Check: −128 + 64 + 16 + 8 + 2 + 1 = −128 + 91 = −37 ✓
Question 4 (Hard) [4 marks]

Explain two advantages of two's complement over sign and magnitude for representing negative integers in a computer.

Mark Scheme (any 2 advantages, 2 marks each = 4 marks):

Advantage 1 — One zero: Two's complement has only one representation of zero (00000000). Sign and magnitude has two (+0 and −0) which wastes a bit pattern and complicates comparisons. [2 marks: advantage + explanation]

Advantage 2 — Simpler arithmetic: Standard addition circuits work identically for positive and negative two's complement numbers. With sign and magnitude, the CPU needs separate logic to handle subtraction. [2 marks: advantage + explanation]

Advantage 3 — Wider negative range: 8-bit two's complement can represent −128, whereas sign and magnitude only reaches −127 — one extra negative value. [2 marks]
Question 5 (Challenge) [4 marks]

A programmer is using 8-bit two's complement integers. They calculate 120 + 10 = 130. Explain what will happen and why, and state the actual value stored.

Mark Scheme:
• 130 is outside the range of 8-bit two's complement (max is +127) [1 mark]
• This is called overflow [1 mark]
• 130 in binary is 10000010; in two's complement this is interpreted as: −128 + 2 = −126 [1 mark]
• The value stored is −126 (a wrong, negative result) [1 mark]
Question 6 (Easy) [2 marks]

State what is meant by the term MSB and explain its role in sign and magnitude representation.

Mark Scheme:
• MSB = Most Significant Bit — the leftmost/highest-value bit [1 mark]
• In sign & magnitude it acts as the sign bit: 0 = positive, 1 = negative [1 mark]
Do not accept "the biggest bit" without context.
Question 7 (Medium) [3 marks]

Write −100 as an 8-bit two's complement number. Show all working. (Hint: 100 = 64 + 32 + 4)

Mark Scheme:
• +100 in 8-bit binary = 01100100 [1 mark]
• Invert all bits → 10011011 [1 mark]
• Add 1 → 10011100 [1 mark]
Verification: −128 + 16 + 8 + 4 = −128 + 28 = −100 ✓
Question 8 (Medium) [3 marks]

A computer uses 4-bit two's complement. State the minimum value, maximum value, and total number of different values that can be represented.

Mark Scheme:
• Minimum value: −2³ = −8 (pattern: 1000) [1 mark]
• Maximum value: +(2³ − 1) = +7 (pattern: 0111) [1 mark]
• Total values: 2⁴ = 16 different values [1 mark]
Question 9 (Hard) [5 marks]

A student says: "Sign and magnitude is better than two's complement because it is easier to understand — you just look at the first bit to know if it's negative."

Evaluate this statement. In your answer, consider both the advantages and disadvantages of sign and magnitude compared to two's complement.

Mark Scheme (max 5 marks):

The student is partially correct:
• ✓ Sign & magnitude is more intuitive — MSB=1 clearly means negative [1 mark]
• ✓ Converting between positive and negative is straightforward — just flip the MSB [1 mark]

However, the student is wrong about "better":
• ✗ Sign & magnitude has two representations of zero (+0 and −0), wasting a pattern [1 mark]
• ✗ Arithmetic is more complex — the CPU needs different circuits for adding positive and negative numbers [1 mark]
• ✗ Two's complement gives one extra negative value (−128 vs −127 for 8-bit) [1 mark]

Conclusion: Two's complement is preferred in real computers despite being less intuitive, because it simplifies hardware design.
Question 10 (Challenge) [4 marks]

The 8-bit two's complement number 11010111 is stored in a register. Show how you would find its positive equivalent, and state that positive value. Explain each step.

Mark Scheme:
• MSB = 1, so the number is negative; to find the magnitude, apply invert & add 1 [1 mark]
• Invert all bits: 11010111 → 00101000 [1 mark]
• Add 1: 00101000 + 1 = 00101001 [1 mark]
• 00101001 = 32 + 8 + 1 = 41 → so 11010111 = −41 [1 mark]
Note: Applying invert & add 1 to a two's complement negative gives you its positive equivalent — the operation is its own inverse!
