🔤 Topic 3.2: Data Representation

How computers encode characters, images & sound

🔤 Why Does Data Representation Matter? ▼ expand
🔤 Text Everywhere

Every email, web page, and document is stored as binary. ASCII and Unicode define how characters map to binary codes — without them, text would be meaningless.

🖼 Images Are Numbers

Every photo on your phone is a grid of pixels, each stored as a binary number. Resolution and colour depth determine quality and file size.

🎵 Sound Is Sampled

Analogue sound waves are converted to binary by sampling at regular intervals. More samples = better quality but bigger files.

⚠️ Bits = Limits

Every binary representation has limits. Fewer bits means lower quality, fewer characters, fewer colours. Understanding these trade-offs is essential.

✏️ Key principle: All data is binary. The encoding scheme (ASCII, Unicode, bitmap, sampling) gives that binary its meaning. More bits = more detail, but also more storage needed.

3.2.1 — Character Encoding: ASCII & Unicode
▼

Computers can only store binary. So how do they store text like the letter A or the symbol @? The answer is character encoding — a mapping that assigns a unique binary code to each character.

DEFINITIONS

Character set — a defined list of characters recognised by computer hardware and software, each assigned a unique binary code.

ASCII — American Standard Code for Information Interchange. A 7-bit character set with 128 characters.

Unicode — a 16-bit (or more) character set that can represent over 100,000 characters from all world languages.

🔤 ASCII (7-bit)

ASCII uses 7 bits per character, giving 27 = 128 possible codes (0–127). It covers:

  • Codes 0–31: Control characters (e.g. carriage return, tab)
  • Codes 32–126: Printable characters (space, A–Z, a–z, 0–9, punctuation)
  • Code 127: Delete
ASCII Examples:
CharacterDenaryBinary (7-bit)
A651000001
B661000010
a971100001

@641000000
Space320100000
✏️ Exam tip: Notice that 'A' = 65 and 'a' = 97. Uppercase letters come before lowercase in ASCII. The difference is always 32.

🌍 Unicode (16-bit+)

ASCII only works for English. Unicode was created to represent every language in the world, plus symbols and emojis.

✏️ Key point: The first 128 Unicode codes are identical to ASCII. ASCII is a subset of Unicode. This means any ASCII text is also valid Unicode.
3.2.2 — Bitmap Image Representation
▼

A bitmap image is made up of a grid of tiny squares called pixels (picture elements). Each pixel is stored as a binary number representing its colour.

DEFINITIONS

Pixel — the smallest identifiable element of a bitmap image. A single square of colour.

Resolution — the number of pixels in an image, expressed as width x height (e.g. 1920 x 1080).

Colour depth — the number of bits used to represent the colour of each pixel.

🎨 Colour Depth

The more bits per pixel, the more colours can be represented:

Colour DepthNumber of ColoursExample
1 bit21 = 2Black & white
2 bits22 = 4Simple icons
8 bits28 = 256GIF images
16 bits216 = 65,536High colour
24 bits224 = 16,777,216True colour (photo quality)

📐 Calculating Image File Size

File Size Formula:
File size (bits) = Width x Height x Colour Depth
Example: A 1920 x 1080 image with 24-bit colour depth:
1920 x 1080 x 24 = 49,766,400 bits = 6,220,800 bytes ≈ 5.93 MB

✏️ Exam tip: When asked about the effect of changing resolution or colour depth, always mention BOTH quality AND file size. Increasing either improves quality but increases file size.
3.2.3 — Sound Representation
▼

Sound is an analogue signal — a continuous wave that varies smoothly over time. Computers are digital — they store discrete binary values. To store sound, we must convert the analogue signal to digital through a process called sampling.

DEFINITIONS

Analogue — a continuous signal that varies smoothly over time (like a sound wave).

Sampling — the process of measuring the amplitude (height) of an analogue sound wave at regular intervals.

Sampling frequency (rate) — the number of samples taken per second, measured in Hertz (Hz).

Sample resolution (bit depth) — the number of bits used to store each sample.

📊 How Sampling Works

1
The analogue sound wave is measured at regular intervals
2
Each measurement is called a sample
3
Each sample is rounded to the nearest value that can be stored in the available bits
4
The sequence of binary samples is stored as a digital sound file

📐 Calculating Sound File Size

File Size Formula:
File size (bits) = Sample rate x Bit depth x Duration (seconds)
Example: 44,100 Hz sample rate, 16-bit depth, 3 minutes:
44,100 x 16 x 180 = 127,008,000 bits = 15,876,000 bytes ≈ 15.1 MB
✏️ Exam tip: CD-quality audio uses 44,100 Hz and 16-bit depth. This is a common exam reference point.
3.2.4 — Limitations of Binary Representation
▼

Every binary representation is limited by the number of bits available. More bits means more detail, but also more storage. Fewer bits means lower quality. This trade-off is fundamental to computing.

🔤 Character Limitations

ASCII (7-bit) Limits
1
Only 128 characters — English only
2
Cannot represent Chinese, Arabic, Hindi, etc.
3
No emojis or special symbols
Unicode (16-bit+) Limits
1
100,000+ characters — covers all languages
2
But each character takes 2+ bytes (larger files)
3
Trade-off: more characters vs. more storage

🖼 Image Limitations

Low Resolution
-
Images appear pixelated (blocky)
-
Edges look jagged (jaggy aliasing)
+
Smaller file size
Low Colour Depth
-
Fewer colours — banding (visible steps between colours)
-
Subtle shades lost (e.g. skin tones)
+
Smaller file size

🎵 Sound Limitations

Low Sampling Frequency
-
High frequencies lost — sounds muffled
-
Aliasing: high frequencies appear as lower false frequencies
+
Smaller file size
Low Sample Resolution (bit depth)
-
Quieter sounds lost — quantisation error
-
Background noise / hissing
+
Smaller file size
KEY TERM

Aliasing — when the sampling frequency is too low to accurately capture the sound wave, causing high-frequency sounds to be misrepresented as lower frequencies. This creates distortion and loss of detail.

✏️ Exam tip: The Nyquist theorem states that the sampling frequency must be at least twice the highest frequency in the sound to avoid aliasing. For human hearing (up to ~20,000 Hz), CD quality uses 44,100 Hz (just over 2 x 20,000).

MED Question 5
[3 marks]
Calculate the file size in bytes of a bitmap image that is 640 pixels wide and 480 pixels high, with a colour depth of 24 bits. Show your working.
Mark Scheme:
  • File size = 640 x 480 x 24 = 7,372,800 bits (1)
  • 7,372,800 / 8 = 921,600 bytes (1)
  • Answer: 921,600 bytes (or approx 900 KB) (1)
MED Question 6
[4 marks]
Explain how an analogue sound wave is converted into a digital representation. In your answer, refer to sampling, sampling frequency and sample resolution.
Mark Scheme (any 4):
  • The analogue sound wave is measured at regular intervals — this is called sampling (1)
  • Sampling frequency is the number of samples taken per second, measured in Hz (1)
  • Each sample measures the amplitude (height) of the wave at that point (1)
  • Sample resolution (bit depth) is the number of bits used to store each sample (1)
  • Each sample is rounded to the nearest value that can be stored in the available bits (quantisation) (1)
  • The sequence of binary samples is stored as a digital sound file (1)
MED Question 7
[3 marks]
Calculate the file size in bytes of a 30-second sound recording sampled at 22,050 Hz with a 16-bit sample resolution. Show your working.
Mark Scheme:
  • File size = 22,050 x 16 x 30 = 10,584,000 bits (1)
  • 10,584,000 / 8 = 1,323,000 bytes (1)
  • Answer: 1,323,000 bytes (or approx 1.26 MB) (1)
HARD Question 8
[4 marks]
Explain the limitations of using a low sampling frequency when converting an analogue sound wave to digital. Refer to the concept of aliasing in your answer.
Mark Scheme (any 4):
  • A low sampling frequency means fewer samples are taken per second (1)
  • High-frequency sounds in the original wave may be missed between samples (1)
  • Aliasing occurs when the sampling frequency is too low to accurately capture the wave (1)
  • Aliasing causes high-frequency sounds to be misrepresented as lower false frequencies (1)
  • This results in distortion and loss of audio quality (1)
  • The Nyquist theorem states sampling frequency must be at least twice the highest frequency to avoid aliasing (1)
HARD Question 9
[6 marks]
A photographer takes a photo with a resolution of 4000 x 3000 pixels and a colour depth of 24 bits. They want to reduce the file size to send it by email.
Discuss the effects of (a) reducing the resolution and (b) reducing the colour depth on the image quality and file size. In your answer, give the original file size in megabytes and explain the trade-offs.
Mark Scheme:
  • Original file size: 4000 x 3000 x 24 = 288,000,000 bits = 36,000,000 bytes ≈ 34.3 MB (1)
  • Reducing resolution: fewer pixels means less detail / image appears pixelated when enlarged (1)
  • But file size decreases proportionally (e.g. half the dimensions = quarter the pixels) (1)
  • Reducing colour depth: fewer bits per pixel means fewer available colours (1)
  • Causes banding — visible steps between similar colours, loss of subtle shades (1)
  • Trade-off: both reduce file size but at the cost of quality. Resolution affects sharpness/detail; colour depth affects colour accuracy. The best approach depends on the image content and how it will be viewed (1)
